## Reflection

Claude was useful for breaking down the Lab 1 requirements into smaller, well-scoped prompts for each GitHub Issue before bringing them into Kiro IDE for implementation.

My prompts included specific constraints such as "follow existing project structure", "use mock Prisma client", and "no hardcoded values" so that the generated code matched the existing conventions and requirements.

I did not rely on the generated output without verification. I inspected every changed file, ran the required tests, checked Git branch status, and reviewed each Pull Request before merging.
